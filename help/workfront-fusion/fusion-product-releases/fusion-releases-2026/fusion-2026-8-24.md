# Workfront Fusion release activity: Week of August 24, 2026

This page describes all enhancements made in Adobe Workfront Fusion the week of August 24, 2026.

For a list of all recent changes, see [Adobe Workfront Fusion release activity](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

For a list of recent bug fixes in Workfront Fusion, see the [Workfront Maintenance Updates](https://experienceleague.adobe.com/en/docs/workfront-known-issues/releases/current-updates) page and check for any updates labeled Workfront Fusion Maintenance Update.

## Fusion webhooks are now secured by default

As of August 23, 2026, Fusion enables authToken-based security by default for all Workfront and Workfront Planning Watch Event module webhook subscriptions, both new and existing. This authenticates payload delivery between Workfront and your Fusion scenario, so your endpoint can verify that incoming requests genuinely originated from Workfront.

This security setting has been applied automatically to all existing Workfront > Watch Event and Workfront Planning > Watch Event module scenarios, as well as any new ones you create going forward. No action is needed on your part to benefit from this protection.

If a specific webhook breaks, or you need to disable this for compatibility reasons, you can turn off the **Enable secured hooks** option on the module's webhook connection. We recommend keeping this setting enabled unless your receiving endpoint specifically cannot support it, since disabling it removes verification that requests are genuinely from Workfront.

For more information, see [Adobe Workfront modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-modules.md) and [Adobe Workfront Planning modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-planning-modules.md).

## Move modules to a chain

To make it easier to create reusable child scenarios, we've created the ability to move a section of an existing scenario directly into a chain, using a right-click option in the scenario editor. 

Previously, chaining scenarios required building the child scenario and updating the parent scenario manually.

Chain functionality is currently in Beta.

For more information, see [Move modules to a chain](/help/workfront-fusion/manage-scenarios/move-modules-to-a-chain.md).
