# Workfront Fusion release activity: Week of August 31, 2026

This page describes all enhancements made in Adobe Workfront Fusion the week of August 31, 2026.

For a list of all recent changes, see [Adobe Workfront Fusion release activity](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

For a list of recent bug fixes in Workfront Fusion, see the [Workfront Maintenance Updates](https://experienceleague.adobe.com/en/docs/workfront-known-issues/releases/current-updates) page and check for any updates labeled Workfront Fusion Maintenance Update.

## Adobe Enterprise Storage Management now available in Workfront Fusion

Workfront Fusion now has a Storage area, giving teams direct access to their Adobe Enterprise Storage Management (ESM) repositories without leaving Fusion. From Storage, you can browse folders, upload and download files, view file version history, and create automation scenarios based on your files.

Storage is owned by teams, and requires your organization to be onboarded to Adobe Identity Management System (IMS) with access to Adobe Storage. Files in Fusion Storage are mirrored in Adobe Files, so any file you can access in Adobe Files, you can also access in Fusion Storage.

For more information, see [Storage overview](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md).

## New Workfront Fusion connector

You can now manage your own Fusion organization from within a scenario, using the new Workfront Fusion connector. Unlike other connectors, which connect Fusion to a third-party app or service, this connector lets a scenario call Fusion's own API, similar to how the Adobe Workfront connector lets a scenario manage Workfront.

With the Workfront Fusion connector, you can:

* Create, read, update, delete, list, and clone records
* Get a record's dependencies
* Export activity logs
* Get queue statistics for a hook
* List the scenarios that reference a connection
* List the Fusion regions and organizations you can access

For more information, see [Workfront Fusion modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md).

## New module in the Workfront Planning connector: Recast record type configuration

You can now retrieve all record types in a workspace, grouped by section, along with each record type's fields and each field's select options, using the new Recast record type configuration module. The output is structured as section > record type > fields.

For more information, see [Adobe Workfront Planning modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-planning-modules.md).

## View Failed and Warning Scenario Runs in the Insights dashboard

The Fusion Insights dashboard now includes a Failed Scenario Executions log, a filterable table of scenario executions across your organization, with error and warning severity shown inline. You can filter by team, scenario, run type, date range, deactivation state, or error message.

You can also select one or more executions and click Activate to re-enable scenarios that were automatically deactivated after repeated failures, without leaving the table.

For more information, see [View the Insights dashboard for an organization](/help/workfront-fusion/set-up-and-manage-workfront-fusion/set-up-and-manage-orgs-and-teams/set-up-orgs-teams-and-users/view-insights-dashboard.md).
