# Workfront Fusion release activity: Week of October 12, 2026

This page describes all enhancements made in Adobe Workfront Fusion the week of October 12, 2026.

For a list of all recent changes, see [Adobe Workfront Fusion release activity](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

For a list of recent bug fixes in Workfront Fusion, see the [Workfront Maintenance Updates](https://experienceleague.adobe.com/en/docs/workfront-known-issues/releases/current-updates) page and check for any updates labeled Workfront Fusion Maintenance Update.

## Federated connections for AWS S3, Azure DevOps, and SharePoint

To make it easier to create secure connections without storing long-lived secrets, we've added federated connection support to the AWS S3, Azure DevOps, and SharePoint connectors.

This lets you use your organization's identity provider to authenticate Workfront Fusion with temporary credentials instead of a client secret or other static credential. It gives you a more secure connection option while keeping the setup process consistent across connectors that already use Azure AD / Microsoft Entra ID or AWS IAM identity providers.

For more information, see:

* [AWS S3 modules](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/aws-s3-modules.md)
* [Azure DevOps modules](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/azure-dev-ops.md)
* [SharePoint modules](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/sharepoint-modules.md)

## Fusion MCP server: Additional tools

To make MCP-based administration easier, we've added several new Adobe Workfront Fusion MCP server tools for managing organizations, teams, users, webhooks, data stores, and feedback. You can now use your connected AI agent to view and manage additional Fusion resources, create and publish scenario versions, and delete specific connections, keys, webhooks, and data structures when needed.

For more information, see [Adobe Workfront Fusion MCP server tools](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-fusion-mcp-server/fusion-mcp-server-tools.md).
