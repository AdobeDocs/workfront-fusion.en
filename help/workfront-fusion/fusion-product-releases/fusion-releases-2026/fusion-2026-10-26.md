# Workfront Fusion release activity: Week of October 26, 2026

This page describes all enhancements made in Adobe Workfront Fusion the week of October 26, 2026.

For a list of all recent changes, see [Adobe Workfront Fusion release activity](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

For a list of recent bug fixes in Workfront Fusion, see the [Workfront Maintenance Updates](https://experienceleague.adobe.com/en/docs/workfront-known-issues/releases/current-updates) page and check for any updates labeled Workfront Fusion Maintenance Update.

## New scenario editor experience

The new scenario editor makes it easier to build and debug scenarios. Your scenarios, mappings, filters, schedules, connections, routers, error handlers, and execution behavior do not change when you switch experiences. You can switch back to the classic experience at any time.

The new experience includes:

* Module cards that show the app icon, module name, description, and module ID, with curved links and status indicators
* Compact view, zoom, Focus, and a minimap for navigating large scenarios
* The ability to fold a router to hide its routes
* Dark mode
* A search-first module browser
* Undo, Redo, and Undo all
* A single panel on the right side of the canvas for module setup, Find and replace, Snippets, Live Trail, and request and response details

To switch between experiences, use the **Try the new design** toggle in the upper-right corner of the scenario editor. Your choice is saved for your user. If you do not see the toggle, the new experience might not be available to your organization yet.

For more information, see [The scenario editor](/help/workfront-fusion/get-started-with-fusion/navigate-fusion/scenario-editor.md).

### Live Trail

Live Trail shows a scenario run as it happens. It combines module requests and run activity in one chronological list. You can search the list, filter it by status, and open the request and response details for any operation.

For more information, see [Use Live Trail to review a scenario run](/help/workfront-fusion/manage-scenarios/live-trail.md).

### Find and replace in the scenario editor

You can now replace a mapped variable, remap references from one source module to another, or copy a connection to other compatible modules, across a whole scenario or in a single module. Find and replace shows a preview of the modules that will be affected before you make the change.

For more information, see [Find and replace variables, sources, and connections in a scenario](/help/workfront-fusion/manage-scenarios/find-and-replace.md).

### Snippets in the scenario editor

You can save selected modules as a snippet and reuse them in other scenarios. You can search, tag, pin, and sort snippets, import and export them, and share them with teams or organizations.

For more information, see [Save and reuse scenario sections with snippets](/help/workfront-fusion/create-scenarios/add-modules/use-snippets.md).

### Temporary debug logs

Request and response details are not kept for every scheduled or triggered run. You can now turn on temporary debug logs in the scenario settings to collect them for the next hour, the next day, the next run, or the next 10 runs. Temporary debug logs are available in the new scenario editor experience only.

For more information, see [Configure scenario settings](/help/workfront-fusion/create-scenarios/config-scenarios-settings/configure-scenario-settings.md#temporary-debug-logs).

### Developer tools built into the scenario editor

Seven Developer Tools are now built into the scenario editor: Get app metadata, Copy mapping, Copy filter, Copy module name, Swap connection, Swap variable, and Remap source. You can use them from a module's context menu, a link's context menu, or the Find and replace panel.

For more information, see [Debug a scenario](/help/workfront-fusion/manage-scenarios/debug-a-scenario.md).

## Adobe CX Coworker connector

The new Adobe CX Coworker connector lets you send a natural-language prompt to Coworker and use its response in a scenario. Coworker interprets your request and can use the tools available to your account to carry out the work.

The connector includes two modules:

* **Run a Prompt:** Starts a new request and, by default, waits for the result.
* **Get Execution Status:** Checks the status of a request that you started earlier.

For more information, see [Adobe CX Coworker modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-cx-coworker-modules.md).

## Insights page updates

The Insights page has several updates that make it easier to find the information you need. This update includes the following features:

* **Customize the page:** Show or hide widgets, or change the order of the widgets on the page. 
* **Refresh all widgets:** Reload the data in every widget while keeping each widget's filters.
* **Take a guided tour:** The first time you open the page, a welcome dialog offers a tour of the widgets and the new controls. 
* **Search scenarios and teams by ID:** In the Organization Operations and Top Scenarios by Operations widgets, the Scenario and Team fields now match on ID as well as name.
* **Dark mode:** The Insights page and its widgets now follow your dark mode setting.
* **Performance widget access:** The Performance widget is now shown only to users with the Organization Edit permission in the active organization, or the Organization View permission on the admin page.
* **Open Organization Operations from a scenario:** You can now open the Insights page with the Organization Operations widget filtered to a specific scenario and team.

For more information, see [View the Insights dashboard for an organization](/help/workfront-fusion/set-up-and-manage-workfront-fusion/set-up-and-manage-orgs-and-teams/set-up-orgs-teams-and-users/view-insights-dashboard.md).
