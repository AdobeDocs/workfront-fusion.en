# Workfront Fusion release activity: Week of September 7, 2026

This page describes all enhancements made in Adobe Workfront Fusion the week of September 7, 2026.

For a list of all recent changes, see [Adobe Workfront Fusion release activity](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

For a list of recent bug fixes in Workfront Fusion, see the [Workfront Maintenance Updates](https://experienceleague.adobe.com/en/docs/workfront-known-issues/releases/current-updates) page and check for any updates labeled Workfront Fusion Maintenance Update.

## New authorization types for custom webhooks

You can now authorize custom webhooks using two new methods: API key auth and HMAC signature. API key auth is now the default authorization type for new webhooks. Previous authorization types are still available, and you can select the empty value for no authorization.

For more information, see [Webhooks](/help/workfront-fusion/references/apps-and-modules/universal-connectors/webhooks-updated.md).

## New Describe with AI button in Scenario description

You can now click Describe with AI in the description field of a scenario's Settings panel to have AI generate a description of the scenario for you automatically, based on the scenario's modules and configuration.

For more information, see [Configure scenario settings](/help/workfront-fusion/create-scenarios/config-scenarios-settings/configure-scenario-settings.md#description).

## Fusion AEM MCP Connector

Send a plain-English prompt to Adobe Experience Manager's own MCP (Model Context Protocol) server, and let an AI model decide which Adobe Experience Manager actions are needed to carry it out. This new dedicated connector adds a single module, Process a user prompt, that:

* Connects to Adobe Experience Manager using OAuth - no manual credentials required.
* Interprets your instruction and calls the needed Adobe Experience Manager actions (sites, assets, content fragments, folders, the content repository, and content AI) to fulfill it.
* Lets you restrict which read-only and write/delete actions the AI is allowed to take, so even an unattended scenario can't take an unexpected destructive action.
* Uses Adobe's own AI service by default, or your own OpenAI, Anthropic Claude, or Amazon Bedrock key if you prefer.

For more information, see [Adobe Experience Manager MCP modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/aem-mcp-modules.md).
