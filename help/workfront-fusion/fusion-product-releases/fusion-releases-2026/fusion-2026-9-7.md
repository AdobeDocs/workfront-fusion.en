# Workfront Fusion release activity: Week of September 7, 2026

This page describes all enhancements made in Adobe Workfront Fusion the week of September 7, 2026.

For a list of all recent changes, see [Adobe Workfront Fusion release activity](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

For a list of recent bug fixes in Workfront Fusion, see the [Workfront Maintenance Updates](https://experienceleague.adobe.com/en/docs/workfront-known-issues/releases/current-updates) page and check for any updates labeled Workfront Fusion Maintenance Update.

## New authorization types for custom webhooks

You can now authorize custom webhooks using two new methods: API key auth and HMAC signature. API key auth is now the default authorization type for new webhooks. Previous authorization types are still available, and you can select the empty value for no authorization.

For more information, see [Webhooks](/help/workfront-fusion/references/apps-and-modules/universal-connectors/webhooks-updated.md).
