## Jira connector: New service account connection types

To make it easier to create Jira connections that match how your team authenticates, we've added two new connection types to the Jira connector: Service account API token and Service account OAuth 2.

These options let you create connections for automation that should run as a dedicated Jira service account instead of a personal user account. Use Service account API token when your Jira service account authenticates with an API token, and use Service account OAuth 2 when your environment uses OAuth 2 for the service account.

Basic and OAuth2 connection types are still available.

For more information, see [Jira modules](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/jira-modules-new.md).
