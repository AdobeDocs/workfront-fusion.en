# Workfront Fusion release activity: Week of November 23, 2026

This page describes all enhancements made in Adobe Workfront Fusion the week of November 23, 2026.

For a list of all recent changes, see [Adobe Workfront Fusion release activity](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

For a list of recent bug fixes in Workfront Fusion, see the [Workfront Maintenance Updates](https://experienceleague.adobe.com/en/docs/workfront-known-issues/releases/current-updates) page and check for any updates labeled Workfront Fusion Maintenance Update.

## Customizable team roles

Each team now has a **Roles** tab where you can create, update, and delete your own roles and choose exactly which permissions each role includes. You are no longer limited to a fixed set of roles. With custom roles, you can give each person only the access their job needs, set up access to match how your organization works, and manage access yourself without contacting support.

For more information, see [View and manage team roles](/help/workfront-fusion/set-up-and-manage-workfront-fusion/set-up-and-manage-orgs-and-teams/manage-users-and-teams/view-and-manage-team-roles.md).

## New Watch records module in the Workfront Fusion connector

The Workfront Fusion connector has a new **Watch records** trigger module. Use it to keep track of what is happening in Fusion without checking manually. The module can watch for new records, updates to existing records, or both, and you can use filters to focus on the changes that matter to your team.

For more information, see [Workfront Fusion modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md).

## MCP preferences for organizations

Organization owners and administrators can now choose which Fusion MCP tools are available to their organization. In the organization details, under **MCP preferences**, you can allow or disable read-only tools and write tools. Write tools require read-only tools to be enabled.

The setting applies to the whole organization. Disabled tools do not appear in the tool list, and Fusion rejects them if an agent calls them. The setting limits only tool calls made through the official Fusion MCP server. Actions that users perform in the Fusion user interface, through the API, or through other integrations are still controlled by each user's own permissions in Fusion.

For more information, see [Manage MCP preferences for your organization](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-fusion-mcp-server/configure-fusion-mcp-server.md#manage-mcp-preferences-for-your-organization).

## Adobe CX Enterprise Coworker: Confirm all tool actions

The **Run a Prompt** module in the Adobe CX Enterprise Coworker connector has a new **Confirm all tool actions** field in the advanced settings. When you turn it on, the module automatically approves supported tool permission requests during that run, up to 20 approval rounds and 100 tool calls. The option is off by default.

Tools might modify or delete data. The option requires **Wait for completion** and a compatible live permission stream, and it is consent for that run only, not a permanent permission grant. Limits, replayed requests, sign-in, questions, and other approvals still need manual review.

For more information, see [Adobe CX Enterprise Coworker modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-cx-coworker-modules.md).
