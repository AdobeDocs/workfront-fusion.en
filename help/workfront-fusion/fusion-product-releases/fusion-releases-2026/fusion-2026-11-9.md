# Workfront Fusion release activity: Week of November 9, 2026

This page describes all enhancements made in Adobe Workfront Fusion the week of November 9, 2026.

For a list of all recent changes, see [Adobe Workfront Fusion release activity](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

For a list of recent bug fixes in Workfront Fusion, see the [Workfront Maintenance Updates](https://experienceleague.adobe.com/en/docs/workfront-known-issues/releases/current-updates) page and check for any updates labeled Workfront Fusion Maintenance Update.

## Customizable team roles

Each team now has a **Roles** tab where you can create, update, and delete your own roles and choose exactly which permissions each role includes. You are no longer limited to a fixed set of roles. With custom roles, you can give each person only the access their job needs, set up access to match how your organization works, and manage access yourself without contacting support.

For more information, see [View and manage team roles](/help/workfront-fusion/set-up-and-manage-workfront-fusion/set-up-and-manage-orgs-and-teams/manage-users-and-teams/view-and-manage-team-roles.md).

## New Workfront templates: Create project with AEM workflow and Create multiple records

Two new automation templates are now available in Workfront Fusion.

* **Create project with AEM workflow:** Creates a project from a project template, and optionally creates the AEM linked folders that are configured for the project template and links them to the new project.
* **Create multiple records:** Creates one or more records on a record type, with one new record for each choice in a multi-select or connected field on the current record. Each new record is linked back to the current record, and you map the fields that are copied to the new records.

For more information, see [Currently available Adobe Workfront Fusion templates](/help/workfront-fusion/create-and-manage-templates/currently-available-fusion-templates.md).

## AI-assisted expression generation

You can now describe what you want in plain language, such as "join these names with a comma" or "add three days to the due date", and AI generates the expression for you. This reduces the trial and error of writing expressions, and the result is readable and easy to review.

AI-assisted expression generation:

* Uses the context of your scenario, including the available mapped fields, field types, destination field, and locale and time zone settings.
* Validates the expression before it is returned, and checks for unsupported functions, missing arguments, unknown field references, and common mistakes with arrays and dates.
* Fixes common syntax mistakes, and replaces recognized workarounds with built-in functions.
* Tries again when validation fails, using specific feedback to regenerate the expression. If it still cannot create a valid expression, it returns a clear error instead of an invalid result.

For more information, see [Generate an expression with AI](/help/workfront-fusion/create-scenarios/map-data/map-using-functions.md#generate-an-expression-with-ai).
