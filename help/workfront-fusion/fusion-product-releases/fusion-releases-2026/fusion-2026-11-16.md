# Workfront Fusion release activity: Week of November 16, 2026

This page describes all enhancements made in Adobe Workfront Fusion the week of November 16, 2026.

For a list of all recent changes, see [Adobe Workfront Fusion release activity](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

For a list of recent bug fixes in Workfront Fusion, see the [Workfront Maintenance Updates](https://experienceleague.adobe.com/en/docs/workfront-known-issues/releases/current-updates) page and check for any updates labeled Workfront Fusion Maintenance Update.

## Webhook queue UI improvements

The webhook queue page has a new layout that matches the Scenarios and Webhooks lists, so it is easier to find and manage queued events. You can now do the following:

* **Search:** Filter the events that are loaded in the queue.
* **Sort:** Sort events by ID, creation date, or size.
* **Navigate:** Change the page size, move between pages, and load additional events.
* **View details:** Open an event's payload in the updated details dialog.
* **Select and delete:** Select individual events, or use Select all to select the entire queue, with optional exclusions. Deleting all events empties the queue. It does not delete the webhook.

For more information, see [View a webhook's queue](/help/workfront-fusion/manage-scenarios/view-webhook-queue.md).


## Adobe Storage: Upload a File module

The Adobe Storage connector has a new **Upload a file** module. The module handles the complete upload in a single step. It creates the destination file, initializes the upload, transfers the file content through a presigned URL, and finalizes the upload, so you no longer need to configure separate transfer and finalization steps. The module supports large files.

For more information, see [Adobe Storage modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-storage-modules.md).
