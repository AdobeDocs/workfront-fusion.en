# Workfront Fusion release activity: Week of September 28, 2026

This page describes all enhancements made in Adobe Workfront Fusion the week of September 28, 2026.

For a list of all recent changes, see [Adobe Workfront Fusion release activity](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

For a list of recent bug fixes in Workfront Fusion, see the [Workfront Maintenance Updates](https://experienceleague.adobe.com/en/docs/workfront-known-issues/releases/current-updates) page and check for any updates labeled Workfront Fusion Maintenance Update.

## Updates to Marketo connector

To allow you to interact with bulk extracts in Marketo, we've added three new modules:

* Create a Bulk Extract Job
* Get Bulk Extract Job Status
* Download a Bulk Extract File

 In addition, we've also added the ability to add a raw JSON request body in the Custom API Call module.

For more information, see [Marketo modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-marketo-modules.md).

## Connect Fusion to your AI agent with the Fusion MCP connector

To enable you to use Adobe Workfront Fusion with AI agents, we've created a Workfront Fusion MCP Server. Now, you can use this server to inspect scenarios, review executions, manage connections, and take approved actions using your existing Fusion permissions. This makes it easier to work with Fusion in natural language without leaving your agent experience.

For more information, see [Configure the Adobe Workfront Fusion MCP server](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-fusion-mcp-server/configure-fusion-mcp-server.md).

## New Adobe Marketo Engage MCP connector

You can now connect Workfront Fusion directly to the Adobe Marketo EngageMCP server, using the new Adobe Marketo Engage MCP connector.

Now, you can enter an open-ended, plain-English instruction, and an AI model decides which Marketo actions are needed to fulfill it.You can restrict which read-only and write/delete actions the AI is allowed to take, so even an unattended scenario can be limited to the actions you approve.

The module can use Adobe's own managed AI service by default, or your own OpenAI, Anthropic Claude, or Amazon Bedrock key if you prefer.

For more information, see [Adobe Marketo Engage MCP module](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-marketo-engage-mcp-module.md).
