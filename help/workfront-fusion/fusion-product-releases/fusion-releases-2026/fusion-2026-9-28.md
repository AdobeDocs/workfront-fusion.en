# Workfront Fusion release activity: Week of September 28, 2026

This page describes all enhancements made in Adobe Workfront Fusion the week of September 28, 2026.

For a list of all recent changes, see [Adobe Workfront Fusion release activity](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

For a list of recent bug fixes in Workfront Fusion, see the [Workfront Maintenance Updates](https://experienceleague.adobe.com/en/docs/workfront-known-issues/releases/current-updates) page and check for any updates labeled Workfront Fusion Maintenance Update.

## New Watch approval events module in the Adobe Workfront Unified Review and Approvals connector

To expand your ability to automate approval workflows in Workfront, we've added a new Watch approval events module to the Adobe Workfront Unified Review and Approvals connector.

With this instant trigger module, you can trigger a scenario when approval-related events occur, such as when an approval is created or updated.

For more information, see [Adobe Workfront Unified Review and Approvals modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-review-and-approvals-modules.md).

## Updates to Marketo connector

To allow you to interact with bulk extracts in Marketo, we've added three new modules:

* Create a Bulk Extract Job
* Get Bulk Extract Job Status
* Download a Bulk Extract File

 In addition, we've also added the ability to add a raw JSON request body in the Custom API Call module.

For more information, see [Marketo modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-marketo-modules.md).
